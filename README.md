# Projeto Batalha Naval em Java

## Bem-vinda ao nosso projeto

Olá professora, seja bem-vinda ao repositório do nosso projeto de Programação.

Este projeto está a ser desenvolvido em Java e tem como objetivo a criação de uma versão do jogo Batalha Naval, aplicando os principais conceitos estudados durante a disciplina, como Programação Orientada a Objetos, estruturas de repetição, estruturas de seleção, ArrayList, funções, classes e manipulação de ficheiros.

Esperamos que este repositório permita acompanhar de forma clara a evolução e organização do nosso trabalho.

## Estrutura das Pastas

O projeto encontra-se organizado da seguinte forma:

- `src` → contém o código-fonte do projeto
- `lib` → contém bibliotecas e dependências utilizadas
- `bin` → contém os ficheiros compilados automaticamente

## Tecnologias Utilizadas

- Java
- Visual Studio Code
- GitHub

## Objetivo do Projeto

Desenvolver um jogo funcional de Batalha Naval executado no terminal, permitindo interação entre jogadores e aplicação prática dos conteúdos aprendidos em aula.

Muito obrigado pela visita ao nosso repositório.
